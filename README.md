# Estudos em Algoritmos
O objetivo deste repositório é registrar meus estudos em algoritmos clássicos da Ciência da Computação.
Optei por implementar principalmente em Python, pois o foco é entender mais o propósito do algoritmo, do que se preocupar com a sintaxe.
Até o presente momento já foi implementado versões iniciais do Algoritmo de Euclides (e sua versão estendida), a Busca Binária e um jogo de advinhação que uso a lógica da busca binária.
